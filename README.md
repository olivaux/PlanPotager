# planpotager
Application Web visant à mettre à disposition une solution de géstion de potager interactive selon une disposition 2D.


Le projet suivant s'appuie sur 
- un backend Java Spring Boot
- un frontend Vue JS + Vite




Pour lancer:

**lancer le backend**
./gradlew bootRun 

**lancer le frontend**
cd frontend
npm run dev (pour Proxy Vite)

**Lancer la base de donnée**
docker compose up -d
